# 模板

## 任务卡

```markdown
# 任务卡 T0000：<一句话标题>

- 发布者：<角色名> ｜ 发布时间：<YYYY-MM-DD HH:mm>
- 优先级：P0 / P1 / P2
- 目标：<一句话说清要达成什么>

## 允许的操作
- 只读 / 读写哪些路径
- 可以点哪些按钮、进哪些页面

## 禁止的操作
- 涉及钱、对外发布、删除、改设置的一律不在此列
- 其他明确不可触碰的范围

## 步骤
1. …
2. …
3. …

## 完成标准
- 可验证的判据（有数字就用数字）

## 停止条件
- 遇到哪些情况立即停止并回执

## 需要回传的证据
- 文字结论 / 截图编号 / 导出文件路径
```

## 回执

```markdown
# 回执 T0000：<同任务卡标题>

- 执行者：<角色名> ｜ 认领时间：<时间> ｜ 完成时间：<时间>
- 结果：已完成 / 失败 / 需确认 / 需人工批准

## 做了什么
- 逐条对应任务卡步骤

## 证据
- 文件或截图路径

## 发现的问题或新情况
- …

## 是否有未执行的步骤及原因
- …
```

## 状态表（STATUS.md）

```markdown
| 任务 | 标题 | 状态 | 更新时间 |
|---|---|---|---|
| T0001 | 示例任务 | 已认领 2026-01-01 10:00 | 2026-01-01 10:00 |
```

状态取值：`待认领` / `已认领` / `已完成` / `失败` / `需人工批准`
